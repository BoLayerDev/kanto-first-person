# Kanto First Person 2.0 Roadmap

## Goal 0 — Foundation

- Preserve original Git history and release hashes.
- Create project rules, status, architecture, provenance, parity, risk, and coordination records.
- Create a private remote, Backup Guardian entry, source checkpoint, and clean-clone restore test.
- Capture creator permission evidence outside Git and publish only a redacted
  hash-bound approval record. Complete for the current legacy-asset inventory.

Exit: the project is recoverable and no legacy artifact is mistaken for reproducible source.

## Goal 1 — Voxel Companion API v1

- Freeze the host-neutral API and ownership rules.
- Add a synthetic reference dispatcher and contract suite.
- Implement isolated adapters for Battle Art and Dramaless Shape.
- Submit both adapter branches to their host owners for review and release.
- Verify callback order, faults, disposal, camera deltas, baseline draw packets,
  and honest optional capability rejection.

Exit: both hosts pass the same conformance suite without runtime source patching
and their owners publish compatible releases.

## Goal 2 — Kernel alpha

- Replace the patcher with a small API 2 entry.
- Add sandbox module loading, host discovery, lifecycle, diagnostics, config, scheduling, LRU, and resource ownership.
- Add no-host, one-host, multi-host, failure, hot-reload, and removal tests.

Exit: `2.0.0-alpha.1` runs as a safe no-op companion on all certified hosts.

## Goal 3 — Static world

- Add interiors, ceilings, doors, windows, posters, caves, pools, rails, and light fittings.
- Add world apron, neighbors, trees, mountains, forest structures, raised props, shadows, and battle props.
- Remove all render-time full-map builds.

Exit: static parity corpus passes with bounded build and resource use.

## Goal 4 — Dynamic world

- Add horizon, sky, stars, clouds, aircraft, wildlife, weather, fog, canopy, vines, grass, particles, and water effects.
- Add ambient audio, one-shots, camera motion, field of view, and depth effects.
- Batch all dynamic families and enforce tier budgets.

Exit: dynamic parity matrix and performance gates pass.

## Goal 5 — Beta

- Complete the legacy option migration.
- Keep corrected Ledge Leap policy and bindings dormant until Gen1recomp adds
  an atomic public movement-attempt API; then integrate and certify it.
- Complete debug tools, upgrade guidance, and all preserved/corrected/retired decisions.

Exit: no unexplained 1.60 parity gap remains.

## Goal 6 — Release candidate

- Run stable and dev engine matrices.
- Complete public synthetic visual tests and private real-game review.
- Complete leak, performance, packaging, supply-chain, and native platform gates.

Exit: `2.0.0-rc.1` is reproducible and all support claims have evidence.

## Goal 7 — Stable

- Create a signed source tag.
- Publish matching root ZIP and `.modpkg` with SHA-256 values and attestation.
- Publish exact compatibility, migration, recovery, and rollback data.

Exit: both host adapters and every claimed platform are certified.

## Companion track — Public field terminal

- Publish an original React Three Fiber showcase at the repository Pages URL.
- Use one fixed-camera 3D diorama behind a compact Gen 1-inspired options menu.
- Support keyboard, pointer, and touch menu navigation plus Red/Blue/Yellow
  atmosphere modes.
- Explain the mod, its Alpha gate, compatibility, safe migration, known limits,
  testing, security, and support routes without distributing ROM-derived art.
- Keep the site build isolated from the Lua runtime and deterministic package.

Exit: the production build passes, the Pages route works, the main journey and
support links pass desktop QA, and mobile behavior passes its separate gate.
