# Security and Integrity

Report a vulnerability through a private GitHub security advisory on the canonical repository. Do not publish exploit details before a fix is available.

KFP 2.0 must not write another mod's files, inspect arbitrary filesystem paths, run external commands, use network access, or request raw engine internals. A report that shows any such behavior is release-blocking.

Do not attach ROMs, saves, credentials, private server exports, or extracted game assets to public reports.
