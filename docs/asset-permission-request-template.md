## Evidence handling

Keep the original message export, account URL, date, surrounding conversation,
asset inventory, and SHA-256 values in the private evidence directory. Commit
only a redacted approval record and evidence hash. Do not publish private names,
email addresses, server IDs, message IDs, or screenshots without permission.

This template is a practical permission record, not legal advice. If ownership
is unclear or a creator cannot make every confirmation, replace or remove the
affected asset before publication.
